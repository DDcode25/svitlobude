# Бот уведомлений об отключениях электроэнергии

Telegram-бот для уведомлений об отключениях электричества по всей Украине. Пользователь выбирает регион и свою группу (очередь) или находит её по адресу, если источник это поддерживает. Бот получает графики из нескольких источников — официальных API операторов и открытых копий их сайтов — и сообщает о предстоящих и изменившихся отключениях.

## Документы

- [Техническое задание](./ТЗ.md) — описание MVP, требований, сценариев и критериев приёмки.

## Статус

На текущем этапе подготовлена спецификация проекта и выбраны источники данных. Исходный код бота и Telegram-токен ещё не настроены.

Источники на старте: API Yasno (Киев, Днепр), API Львовобленерго и JSON-зеркала сообщества для остальных регионов. Для 7 регионов готового источника нет, они запланированы на второй этап. Подробности — в разделе 3 [ТЗ](./ТЗ.md).

Стек: Python и [Telethon](https://docs.telethon.dev/) в режиме бота. Для запуска понадобятся токен бота от @BotFather, а также `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org).

Открытые вопросы перечислены в разделе 10 ТЗ.

## Планируемые возможности

- Выбор региона, оператора и группы отключений; поиск группы по адресу там, где источник это поддерживает.
- Подписка на уведомления о плановых отключениях.
- Предупреждение перед отключением и уведомление об изменениях графика.
- Просмотр актуального расписания по запросу.
- Настройки времени уведомлений и часового пояса.

Подробные требования и границы MVP приведены в [ТЗ](./ТЗ.md).
