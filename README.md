# Бот уведомлений об отключениях электроэнергии

Telegram-бот для уведомлений об отключениях электричества по выбранной очереди (группе или подгруппе) и, при необходимости, населённому пункту. Бот получает расписание из настраиваемого официального источника и сообщает пользователям о предстоящих и изменившихся отключениях.

## Документы

- [Техническое задание](./ТЗ.md) — описание MVP, требований, сценариев и критериев приёмки.

## Статус

На текущем этапе подготовлена спецификация проекта. Исходный код бота, Telegram-токен и источник расписания ещё не настроены.

Перед началом разработки необходимо определить:

1. Область, город или населённый пункт, для которого будет работать бот.
2. Официальный сайт или API поставщика электроэнергии с графиками.
3. Формат очередей, используемый источником (например, группа и подгруппа).
4. Частоту обновления расписания и желаемые сроки предупреждений.

## Планируемые возможности

- Выбор населённого пункта и очереди отключений.
- Подписка на уведомления о плановых отключениях.
- Предупреждение перед отключением и уведомление об изменениях графика.
- Просмотр актуального расписания по запросу.
- Настройки времени уведомлений и часового пояса.

Подробные требования и границы MVP приведены в [ТЗ](./ТЗ.md).
